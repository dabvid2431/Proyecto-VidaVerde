# Vida Verde

Tienda en línea de productos naturales: cosmética orgánica, suplementos puros, cafés y tés infusionados.

## Características

- Catálogo de 24+ productos
- Buscador y filtrado por categoría
- Carrito de compras con localStorage
- Integración con WhatsApp para pedidos
- Diseño responsivo (móvil y escritorio)

## Tecnologías

- HTML5, CSS3, JavaScript
- Tailwind CSS
- LocalStorage para persistencia

## Cómo usar

1. Clonar el repositorio:
```bash
git clone https://github.com/dabvid2431/Proyecto-VidaVerde.git
```

2. Servir localmente:
```bash
python -m http.server 8000
```

3. Abrir en navegador:
```
http://localhost:8000
```
